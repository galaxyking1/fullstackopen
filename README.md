## 🚀 How to Run a Project
Each part contains specific exercises and projects. To run a project locally:
1. Clone this repository: `git clone https://github.com/galaxyking1/fullstackopen.git`
2. Navigate to the specific part/project folder.
3. Install dependencies: `npm install`
4. Start the development server: `npm run dev` (or `npm start`)
